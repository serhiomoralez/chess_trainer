ШАХМАТНЫЙ ТРЕНЕР — ПРОТОТИП 0.1

Состав:
- index.html — приложение
- manifest.webmanifest — настройки установки как PWA
- sw.js — базовый service worker

Сейчас работает:
- шахматные правила через chess.js 1.4.0 (загружается с CDN)
- выбор стороны, игра касанием, легальные ходы
- случайный тренировочный соперник
- история ходов и сохранение завершённых партий в localStorage

Пока НЕ реализовано:
- Stockfish и сильный соперник
- подробный анализ ошибок
- адаптивная сила соперника и долговременная статистика ошибок

Для установки на Android нужен HTTPS-хостинг (например, GitHub Pages).
Открой сайт в Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
Для первой загрузки нужна сеть, так как chess.js берётся с CDN.
Это прототип: не используй его как единственное хранилище важных партий.
